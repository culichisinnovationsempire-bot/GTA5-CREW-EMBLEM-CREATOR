# GTA V Crew Emblem SVG Generator

A browser-based SVG generator for creating GTA V crew emblems.  
Draw freehand, trace images, and export clean SVG code.

## Features
- Freehand drawing canvas
- Adjustable stroke color + width
- Load an image for tracing
- Export SVG code
- 100% client-side
- Works on GitHub Pages

## Rockstar Upload Note
Rockstar Social Club does **not** accept raw SVG uploads.  
You must convert the SVG into Rockstar emblem editor commands.

This project provides the SVG.  
A converter script can be added later.

## How to Use
1. Open `index.html` in your browser.
2. Draw or load an image.
3. Click **Export SVG**.
4. Copy the SVG from the textbox.

## Deploy on GitHub Pages
1. Push this project to a GitHub repo.
2. Go to **Settings → Pages**.
3. Set source to `main` → `/root`.
4. Your generator will be live.
